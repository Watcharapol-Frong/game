# Game art assets

One subfolder per game — `game1/`, `game2/`, `game3/`, `game4/`. Upload files
into the matching folder on GitHub (path: `src/assets/game<N>/`) and Claude
wires them into the code.

- `game1/` — done (Jane's Cactus Care / BART).
- `game2/`, `game3/`, `game4/` — waiting on art. See the asset checklist for
  the exact file list, suggested filenames, and size guidance for each game.

File type: WebP preferred (PNG for anything needing hard transparency edges).
Keep each file under ~150KB where possible.
